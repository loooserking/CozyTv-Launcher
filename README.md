# stvlauncher

A minimal, premium, apple-inspired Android TV launcher.

## Features
- Ultra-clean, distraction-free design.
- Premium Red and Black color scheme.
- Quick access to Inputs, Wi-Fi, Bluetooth, and Settings directly from the homepage.
- Minimalistic interface designed for focus.

## Building
To build this project, use:
```bash
./gradlew assembleDebug
```
The APK will be located in `app/build/outputs/apk/debug/app-debug.apk`.
